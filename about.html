🛡️ 防诈骗指南

近期冒充运动员、伪造官方活动的诈骗增多，请务必警惕以下情况：

  1. 任何自称"孙颖莎/王楚钦本人/经纪人/亲属"的私信都是假的。运动员不会通过私信联系球迷索要钱财、个人信息或要求转账。
  2. 非官方渠道的"粉丝见面会""独家合影""签名周边预售"需高度警惕。一切活动以中国乒协、WTT、运动员本人社交账号公告为准。
  3. 声称能"代购内部票/工作证/后台通行证"的，99%是骗局。赛事门票只通过官方渠道（大麦、猫眼、赛事官网）发售。
  4. 不要点击不明链接或扫描来路不明的二维码。尤其警惕伪装成"赛事直播入口""投票链接"的钓鱼网站。
  5. 不向任何人透露你的银行卡号、验证码、身份证号。真正的官方活动绝不会用这些方式向你索要信息。
  6. 如遇可疑情况，保留截图证据，向平台举报并报警。你的一次举报可能保护其他球迷免受损失。

🤝 文明观赛倡议

喜欢孙颖莎和王楚钦，最好的方式是用文明、理性的方式支持他们：

  1. 最好的距离，是球台和观赛席。尊重运动员的私人空间和日常生活，不跟拍、不蹲酒店、不打扰训练。
  2. 场上全力以赴是对手，场下都是为国争光的队友。拒绝拉踩、辱骂任何一位运动员——每一位站上赛场的选手都值得尊重。
  3. 不传谣、不信谣。关于运动员的私生活、伤病、队内关系等未经官方证实的信息，不传播不讨论。谣言止于智者。
  4. 理性看待输赢。体育的魅力在于不确定性。赢了一起庆祝，输了给予鼓励。真正的球迷是运动员最坚实的后盾，无论胜负。
  5. 文明发言，友好讨论。论坛里可以有不同的观点，但请保持礼貌。人身攻击、引战、恶意刷屏的行为不被容忍。

❤️ 给球迷朋友的话

这个站是一个球迷为球迷建的小角落。没有商业目的，不追求流量，只是想给喜欢孙颖莎和王楚钦的朋友们留一个能安静看球、认真聊天的地方。

论坛接入

静态站本身没有数据库，所以论坛要真正能发帖，二选一：

A方案一：Giscus（推荐 · 免费）

基于 GitHub Discussions，零成本托管，适合球迷站。步骤：

1. 把站点代码传到 GitHub 公开仓库；
2. 装 Giscus App 到该仓库，开启 Discussions；
3. 去 giscus.app/zh 生成配置，把生成的 <script> 贴进 forum.html；
4. 在 data.js 的 FORUM_BACKEND 填 repo/repoID 并设 enabled:true。

B方案二：自建后端

想要完全可控（发帖/审核/数据归属）就自建。任意语言写个 REST API，main.js 里 FORUM_BACKEND.apiBase 指向你的服务即可，initPostModal 已写好 fetch 调用点。

提醒：自建需自担服务器成本与内容合规审核责任。
